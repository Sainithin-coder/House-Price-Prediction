🧠 Joint Self-Attention Model Architecture
📊 Numerical
17 features
→
🔄 Self-Attn ×2
Intra-modal

⚡ Joint Cross-Attention
Inter-modal Fusion
→
🧠 MLP Head
→ ₹ Price
Categorical: 6 embeddings → Self-Attn ×2 ↗ (feeds into Cross-Attention above)
01

Feature Tokenization

Each numerical feature projected to d_model=64 token. Categorical features embedded via learnable Embedding layers.

02

Intra-Modal Self-Attention

Two stacked Multi-Head Self-Attention blocks (4 heads each) process numerical and categorical token sequences independently.

03

Joint Cross-Attention (Fusion)

Bidirectional cross-attention: numerical queries over categorical KV, and categorical queries over numerical KV — inter-modal fusion.

04

MLP Regression Head

Mean-pool both streams → concat → 256→128→64→1 MLP with GELU activations → final price (INR).
