🧠 Model Architecture

Joint Self-Attention Network for Heterogeneous Data Analysis

01

Feature Tokenization

Each numerical feature is projected into a d_model=64 dimensional token via a learnable linear projection. Categorical features are embedded using dedicated Embedding layers with vocabulary sizes matching dataset cardinality.

02

Intra-Modal Self-Attention

Two stacked Multi-Head Self-Attention (MHSA) blocks process the numerical token sequence and categorical token sequence independently. Each block uses 4 attention heads and residual connections with LayerNorm.

03

Joint Cross-Attention

The inter-modal fusion stage: numerical tokens query over categorical keys/values, and categorical tokens query over numerical keys/values — forming bidirectional joint self-attention that captures cross-modal dependencies.

04

Regression Head

Both fused streams are mean-pooled and concatenated into a 128-dim vector, then passed through a 3-layer MLP (256→128→64→1) with GELU activations and dropout for robust regression.
